# RAG_new archive

This directory contains retained history that is not part of the active
documentation or runtime surface. Nothing here should be used to select new
work without confirmation from `CURRENT_STATE.md` and `ROADMAP.md`.

## Contents

| Path | Contents |
|---|---|
| `docs/plans/` | Superseded delivery and remediation plans |
| `docs/sessions/` | Session handoffs and agent journals |
| `docs/state/` | Long-form agent-state history |
| `docs/status/` | Superseded closure and backlog snapshots |
| `docs/research/` | Dated research snapshots |
| `docs/design/` | Superseded design-process artifacts |
| `tasks/` | Completed Codex task specifications and verification reports |
| `legacy-code/` | Removed compatibility code and its tests |
| `process/` | Historical workflow diagnostics |

Files were consolidated here on 2026-09-04. Their internal links and status
claims may describe the repository as it existed on their original dates; they
are preserved as evidence rather than continuously rewritten.
